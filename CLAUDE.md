# Project Instructions

## Commits

Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for every commit message:

```
<type>(<optional scope>): <short imperative summary>

<optional body>

<optional footer(s)>
```

- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
- Scope is optional and should name the module when useful (e.g. `payments`, `orders`, `telegram`).
- Summary: lowercase, imperative mood, no trailing period, ≤ 72 characters.
- Mark breaking changes with `!` after the type/scope and a `BREAKING CHANGE:` footer.
